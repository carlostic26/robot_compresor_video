# Guía de colores de la app

## Paleta principal

Esta paleta está diseñada para un tema oscuro, tecnológico y profesional, con tonos de gris oscuro y acentos en azul-cian para transmitir una sensación de herramienta de procesamiento y compresión de video.

### Colores base

- Primario: `#4FC3F7`
- Primario oscuro: `#29B6F6`
- Fondo: `#10151C`
- Superficie: `#1A2230`
- Texto principal: `#E6ECF5`
- Texto secundario: `#7A879C`
- Acento: `#5E81AC`
- Éxito: `#76C893`
- Error: `#FF6B6B`

## Uso recomendado

- Usar el fondo oscuro como base general de la interfaz.
- Usar la superficie para tarjetas, panels y secciones elevadas.
- Usar el color primario para botones, acciones principales y elementos interactivos.
- Usar el acento para resaltar estados, detalles técnicos o indicadores secundarios.
- Usar el verde de éxito para estados positivos y el rojo de error para alertas.

## Nota de diseño

Se evitó el uso de negro puro para mantener una estética más refinada, tecnológica y menos agresiva visualmente.
